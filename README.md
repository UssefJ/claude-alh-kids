# Al Himmah Kids — servervariant 1.1

Begin bij [START-HIER.md](START-HIER.md) voor installatie binnen je bestaande GitHub-, Supabase- en Cloudflare-accounts. Gebruik afzonderlijke projecten naast Quwa.

- Publieke kinderapp met zes categorieën.
- Aparte beveiligde beheeromgeving op `/beheer/`.
- Centrale concepten, publicaties en media via Supabase.
- Quran met volledige opnames en ayahmarkeringen; gebed met audio per zin; selectie en herhalen; verhalen met één doorlopende opname.
- CRUD, slepen/uploaden, ayahmarkeringen en JSON-surahpakketten.

`npm ci`, `npm run check`, `npm test`, `npm run build` (met publieke Supabase-omgevingsvariabelen).

Dit is de eerste serverbasis voor een presentatie, nog geen live geïnstalleerde of op grote belasting geteste productieomgeving.

Zie [UPDATE-1.1.md](UPDATE-1.1.md) voor overstappen vanaf de vorige servervariant.
